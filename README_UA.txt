ДРУГИЙ ЕКРАН: планшет Toshiba AT200 + ноутбук Windows 10
=========================================================

ЯК ЗІБРАТИ (раз, без встановлення будь-чого на ноутбук)
1. На github.com створіть новий репозиторій (наприклад second-screen).
2. Розпакуйте цей архів і перетягніть ВСЕ вміст у репозиторій (Add file -> Upload files),
   разом з папками .github, android, windows. Натисніть Commit.
3. Відкрийте вкладку Actions -> дочекайтесь зеленої галочки (2-4 хв).
4. У кінці сторінки запуску, розділ Artifacts, завантажте:
   - TabMonitor-Tablet-APK  -> TabMonitor.apk  (для планшета)
   - TabMonitor-PC          -> TabMonitor.exe + adb  (для ноутбука; розпакуйте в одну папку)

ВСТАНОВЛЕННЯ
- Планшет: скопіюйте TabMonitor.apk, встановіть (дозвольте «невідомі джерела»).
- Ноутбук: нічого не ставити, просто запустіть TabMonitor.exe.

КАБЕЛЬ (рекомендовано) — два способи, програма сама пробує обидва
 А) USB-модем (без драйверів):
    Планшет: Налаштування -> Ще/Бездротові мережі -> Режим модему -> USB-модем (увімкнути).
    Підключіть кабель до ноутбука. Відкрийте на планшеті «Другий екран».
    На ноутбуці: «Запустити».
 Б) USB-налагодження (adb, швидше і без модему):
    Планшет: Налаштування -> Для розробників -> USB-налагодження (увімкнути).
    Підключіть кабель (може знадобитись драйвер Toshiba/Google USB). Решта як вище.
    adb.exe лежить поруч з TabMonitor.exe — тримайте їх в одній папці.

WI-FI
 Обидва пристрої в одній мережі. Адреса планшета показана на його екрані очікування.
 Впишіть її в поле «IP планшета» на ноутбуці і натисніть «Запустити».

КЕРУВАННЯ
 - Дотик = клік/перетягування мишею, два пальці = права кнопка.
 - Кнопка «Назад» двічі — вихід із програми на планшеті.

ВАЖЛИВО: ЗВИЧАЙНЕ ДЗЕРКАЛО ЧИ РОЗШИРЕНИЙ ЕКРАН
 Без додаткового драйвера планшет ДЗЕРКАЛИТЬ вибраний екран ноутбука.
 Щоб був справжній другий монітор (розширення робочого столу), на ноутбук треба поставити
 безкоштовний віртуальний монітор, напр. «Virtual Display Driver» (MttVDD / IddSampleDriver)
 або usbmmidd_v2. Після цього в списку екранів програми з'явиться «Екран 2» — виберіть його.

Якщо не підключається: перевірте, що на планшеті відкрита програма (видно «Очікую підключення»),
і що брандмауер не блокує TabMonitor.exe.
